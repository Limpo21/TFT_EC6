# TFT_EC6

**Архивная версия.** Ранняя графическая библиотека для Arduino —
предок [LinkerGFX](https://github.com/Limpo21/LinkerGFX).
Сохранена «как есть» для истории разработки. Не предназначена для
использования в новых проектах.

## Что это

Библиотека для цветного TFT-дисплея на контроллере ST7735
(160×160, RGB565) под платформу Arduino. Написана с нуля,
без сторонних зависимостей — только Arduino.h.

Возможности:

- попиксельный вывод, заливка прямоугольников, очистка экрана;
- линии (алгоритм Брезенхема) с задаваемой толщиной;
- прямоугольники, треугольники и круги: залитые и контурные;
- поворот экрана на 0/90/180/270°;
- вывод форматированного текста `DrawPrintf` (аналог printf)
  встроенным шрифтом 5×7 с масштабированием;
- 24-битный цвет на входе (`0xRRGGBB`), преобразование в RGB565.

## Ограничения (эпоха «первой версии»)

- **Программный SPI**: каждый бит передаётся вручную через
  `digitalWrite`, поэтому отрисовка медленная, а заливка больших
  областей занимает заметное время.
- **Нет кадрового буфера**: запись идёт прямо в память дисплея,
  промежуточные состояния не скрываются.
- **Один шрифт**, только латиница; кириллица и UTF-8 не поддерживаются.
- **Нет спрайтов, картинок и прозрачности.**
- API с избыточными вариантами функций, часть реализаций
  незавершена (код сохранён в том виде, в каком был).

## История и продолжение

Библиотека написана одним разработчиком (Limpo21) как учебный
проект: под конкретную задачу подходящей библиотеки не нашлось.
Работа над ней показала, что архитектуру нужно менять, — так
началась разработка [LinkerGFX](https://github.com/Limpo21/LinkerGFX):
аппаратный SPI, собственный printf, UTF-8 и кириллица, спрайты,
поддержка AVR / ESP32 / STM32.

Лицензия: не предоставлена. Код выложен только как демонстрация
истории разработки; использование не разрешено.
